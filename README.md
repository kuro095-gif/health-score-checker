# 보건직 공무원 응시 학생 학과성적 기준 검토 도구

성적 엑셀 파일을 업로드하고 검토 대상 학생을 입력하면 보건직 공무원 응시 학생의 학과성적 기준 충족 여부를 자동 계산하는 정적 React 웹앱입니다. 모든 계산은 사용자의 브라우저 안에서만 처리되며, 업로드한 엑셀 파일은 서버로 전송되거나 저장되지 않습니다.

## 주요 기능

- `.xlsx` 성적 파일 업로드 및 전체 시트 읽기
- 분석 시트 선택, 헤더 행 번호 수정, 열 매핑 직접 수정
- 학번/이름 기반 학생 검색 및 이름 불일치·동명이인·자료 없음 안내
- 전문교과 기준 ①, ②와 보통교과 기준 ③ 자동 계산
- 학생별 판정 결과표, 상세 산출 내역, 정렬·필터·검색
- 엑셀 다운로드, jsPDF 기반 PDF 다운로드, 브라우저 인쇄/PDF 저장

## 설치 방법

```bash
npm install
```

## 개발 서버 실행 방법

```bash
npm run dev
```

## 빌드 방법

```bash
npm run build
```

빌드가 끝나면 `dist` 폴더에 정적 배포 파일이 생성됩니다.

## 배포 방법

### GitHub Pages

1. GitHub 저장소에 프로젝트를 올립니다.
2. 저장소 이름이 `username.github.io`가 아니라면 `vite.config.ts`에 아래처럼 저장소 이름을 base로 지정합니다.

```ts
export default defineConfig({
  plugins: [react()],
  base: "/저장소이름/",
});
```

3. `npm run build`를 실행합니다.
4. GitHub Pages 설정에서 `dist` 빌드 결과를 배포하도록 GitHub Actions를 구성하거나, `gh-pages` 같은 배포 도구로 `dist`를 게시합니다.

### Netlify

- Build command: `npm run build`
- Publish directory: `dist`

### Vercel

- Framework Preset: `Vite`
- Build Command: `npm run build`
- Output Directory: `dist`

## 사용 방법

1. 웹앱 링크에 접속합니다.
2. 성적 엑셀 파일을 업로드합니다.
3. 읽은 시트 목록에서 분석할 시트를 선택합니다.
4. 헤더 행 번호와 열 매핑을 확인하고 필요하면 수정합니다.
5. 검토 대상 학생을 한 줄에 한 명씩 입력합니다.
6. `충족 여부 계산하기` 버튼을 누릅니다.
7. 결과표를 확인하고 필요하면 상세보기를 엽니다.
8. 엑셀 다운로드, PDF 다운로드, 인쇄/PDF 저장 기능으로 결과를 출력합니다.

## 계산 기준 설명

최종 충족 여부는 아래 조건을 모두 만족해야 `충족`입니다.

```text
최종 충족 여부 =
① 충족 AND ② 충족 AND (③-1 충족 OR ③-2 충족)
```

### ① 전문교과 성취도 평균 B 이상

성취도는 다음 점수로 환산합니다.

| 성취도 | 점수 |
| --- | ---: |
| A | 1 |
| B | 0 |
| C | -1 |
| D | -2 |
| E | -3 |

전문교과 평균 산출값:

```text
전문교과 이수과목 성취도 환산점수 합계 ÷ 전문교과 총 이수과목 수
```

산출값이 `0 이상`이면 ①을 충족합니다.

### ② 전문교과 A 비율 50% 이상

```text
전문교과 성취도 A 이수과목 수 ÷ 전문교과 총 이수과목 수 × 100
```

산출값이 `50 이상`이면 ②를 충족합니다.

### ③ 보통교과 기준

보통교과는 아래 둘 중 하나만 만족해도 충족합니다.

```text
평균 석차비율 ≤ 50
또는
평균 석차등급 ≤ 4.5
```

평균 석차등급:

```text
Σ(과목별 학점 × 과목별 석차등급) ÷ Σ(과목별 학점)
```

평균 석차비율:

```text
Σ(과목별 학점 × 과목별 석차비율) ÷ Σ(과목별 학점)
```

석차등급 또는 석차비율이 빈칸, `0`, `-`, `미산출`, `P`, `이수`, `미이수` 등인 과목은 해당 계산에서 제외합니다.

## 개인정보 보호 안내

- 성적 파일은 사용자의 브라우저에서만 처리됩니다.
- 파일과 학생 성적 데이터는 서버로 전송되거나 저장되지 않습니다.
- 같은 링크로 접속하더라도 각 사용자의 파일은 각자의 컴퓨터에서만 계산됩니다.
- 새로고침하거나 브라우저 탭을 닫으면 메모리에 있던 업로드 자료는 사라집니다.
